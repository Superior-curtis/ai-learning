# AI 產業價值鏈

> 📅 2026-08-04 · 核心概念
> 從 GPU 晶片到終端用戶，AI 產業像一條分層的河流。看懂每一層誰在賣、誰在買、利潤在哪，才能看懂這門生意。

---

當一個提示詞送進模型，光速回答背後其實牽動一整條產業鏈：**晶片 → 雲端運算 → 模型實驗室 → 模型 API → 應用與基建層 → 終端用戶**。每一層都是獨立的生意，各有賣家、買家，也各有自己的毛利與護城河。

這一篇把這條價值鏈拆開。看懂它在哪一段最賺錢，你就踏進了「AI 是門生意」的大門。

## 一個提示詞背後的產業鏈

打開任何聊天框，你眼睛看到的只有最後那一層。但往下挖，是這樣堆疊起來的：

```text
[ 晶片 / GPU ]     — 輝達 (NVIDIA) 這類，賣「算力磚塊」
      ↓ 賣給
[ 雲端 / 運算 ]    — AWS / GCP / Azure，出租 GPU 小時
      ↓ 賣給
[ 模型實驗室 ]     — OpenAI / Anthropic / Google / DeepSeek，煉出權重
      ↓ 透過
[ 模型 API ]       — 按 token 計費地把模型能力出租
      ↓ 賣給
[ 應用 / 基建層 ]  — 客服、寫作、代理平台，包裝給使用者
      ↓ 賣給
[ 終端用戶 ]        — 你付費給 SaaS、企業付費給內部部署
```

每一層都對下一層收費，也把自己的成本轉嫁給下一層。整條河的源頭是晶片，入海口是你手機上的那個 App。

## 各層在賣什麼

| 層級 | 賣家例子 | 賣的是 | 買家 |
|---|---|---|---|
| **晶片 / GPU** | NVIDIA、AMD、Cerebras | 算力硬體 + 互連 | 雲端廠商、實驗室 |
| **雲端 / 運算** | AWS、Azure、GCP | 以小時計的 GPU 與網路 | 模型實驗室、企業 |
| **模型實驗室** | OpenAI、Anthropic、Google、DeepSeek | 訓練出的模型權重 | 自己或透過 API 賣出 |
| **模型 API** | 各實驗室的 API 產品 | 按 token 計費的推理 | 開發者、應用公司 |
| **應用 / 基建層** | 各種 SaaS、代理、整合平台 | 打包好的功能與介面 | 終端用戶、企業 |
| **終端用戶** | 你、你的公司 | —（付費方） | — |

## 利潤在哪裡最集中

不是每一層都賺同樣的錢，關鍵看**「誰握著不可或缺的稀缺資源、且對手難以替代」**：

* **護城河最寬：晶片。** 全世界想做大模型，幾乎都得先經過輝達的 GPU 與其互連生態（CUDA）。它同時賣「鏟子」跟「通路」，供不應求時還有定價權。
* **次之：頂級雲端。** 雲廠商有資本與規模，能把幾萬張 GPU 組成的叢集租出去，還附帶網路、儲存、安全這個完整生態——單買 GPU 養不起巨量推理。
* **劇烈競爭：模型實驗室。** 最醒目、也最燒錢。每幾個月要花數億美元重煉一次模型（見 `train-01-pretraining`），來維持排行榜前段班。品質一旦落後，客戶就流向別家。
* **毛利分化：應用層。** 天花板差很大：包裝成「生產力工具」能收費，做成好看的玩具就被蒸發。真正值錢的是把 AI 嵌進**已有工作流**、能證明省錢或增量的那一類。

一句話：**價值鏈越上游越「賣鏟子」、越抗跌；越下游越「挖金礦」但越要靠應用場景證明自己。**

## 為什麼「地主」往往比「挖礦者」更穩

歷史上的淘金熱都有一個規律：**真正穩定賺大錢的，常是賣鏟子、賣水、賣工具給淘金客的人。** AI 這個週期也不例外——需求最確定、不受單一模型成敗影響的是提供基礎設施者。

三大雲廠商同時也在做一個**策略動作：垂直整合**。它們自己開實驗室、自己煉模型、自己賣 API，把「雲端 + 模型 + API」綁在一起，讓客戶在一個帳單裡買齊。這讓純做單層的玩家壓力變大。

## 每一層都在向「集中」塌縮

這條價值鏈最反直覺的一點：**每一層的玩家都極度集中。** 晶片層近乎一家獨大，雲端層是三家，旗艦模型層是四個名字，開放權重層也是幾個家族在輪流登頂。

集中不是巧合，而是這個產業的物理：

* **資本門檻極高。** 煉一個頂級模型要數億美元的單（見 `train-01-pretraining`），不是每家公司都玩得起。
* **網路效應。** 開發者、框架、生態都往市場最大的那幾個身上長，越多人用就越難被取代。
* **人才集中。** 能做頂尖模型、能調度數萬張 GPU 的人屈指可數，且匯流向資金最充足的地方。

所以每一層都是「少數玩家出牌」。看懂這點，就不會對「為什麼明星新創那麼少、新聞都是那幾家」感到意外。

## 用「毛利」當每一層的量尺

不同層的生意，衡量健康的指標也不同。一條實用的量尺：**這層的毛利結構長什麼樣。**

| 層級 | 主要成本 | 毛利特徵 | 關鍵指標 |
|---|---|---|---|
| **晶片 / GPU** | 製程、研發、產能 | 高且穩（供不應求時有定價權） | 出貨量、市佔、生態鎖定 |
| **雲端 / 運算** | 資本支出、電力、維運 | 規模攤薄後改善 | 使用率、資本回報 |
| **模型實驗室** | 訓練 + 推理 | 高營收、毛利待攤平 | 推理成本、留存、API 營收 |
| **應用 / 基建** | 推理轉嫁 + 獲客 | 分化最大 | 毛利 × 留存 |

記住：**毛利比營收更能說明這層是否「站得住」。** 營收是風光，毛利是體質。

## 上游做整合，常見的一種「價值再分配」

把鏡頭拉遠，會看到一個一再重演的動作：**上游往下做整合，把下游的毛利收進自己口袋。**

雲端廠自己開實驗室、自己賣模型與 API，等於把「算力 + 能力 + 計價」綁成一包。純做「轉售算力」的薄層中介，會被這一包直接夾扁。

這不是道德判斷，而是商業重力的方向：**誰離最終付費者最近、又握有不可取代的資源，誰就越能把價值鏈的利潤往上收攏。** 這就是為什麼「應用層必須靠場景與資料築牆」——否則那層的毛利遲早被上游吸走。

## 只看晶片與雲端仍然不夠

但把 AI 產業簡化成「只有 NVIDIA 跟雲端」，會漏掉真正的經濟細節：**推理成本**。想法已經訓練好的模型，每次回答都要實際花電力、花 GPU 時間去「算」——這才是決定應用層生意能不能賺錢的分母。

這一篇先埋個伏筆：**跑一次回答的成本結構，決定了很多公司定價與生死**。我們在 `econ-01-inference-cost` 會真正攤開這張帳單。

> 要記住的一件事：AI 價值鏈是「上游靠稀缺資源、下游靠應用場景」的分層生意。每一層其實都在做同一件事——把「猜下一個字」這台機器（llmcore-01），收費包裝成服務賣給下一層。

## 一張十元帳單，走完整條鏈

抽象講「錢往上游集中」，不如跟一張帳單走一遍。假設你為一次 AI 功能付 10 元（示意數字，非真實拆帳），錢是這樣分層流動的：

```text
你付 $10 → 應用公司
↓ 留 $4（包裝、客服、獲客）
應用付 $6 → 模型 API
↓ 抽 $3（計費、平台）
實驗室/雲端收 $3 → 付 $1.5 買 GPU 與雲服務
↓
輝達(晶片) 最終收到約 $1.5
```

三個重點：

* **越下游越早收錢，但留下來的不多。** 應用拿得最早，但要付客服、獲客與 API；能留下的取決於毛利。
* **上游收得少，但幾乎是「淨的」。** 輝達收到的那 $1.5 幾乎全是毛利——這正是「賣鏟子」的意義。
* **整條鏈的錨點是「你願不願意付那 $10」。** 終端需求一旦撐不住，每一層的分成都會同步縮水。

## 這張地圖怎麼用

看懂價值鏈不是為了背名詞，是為了回答三種實際問題：

1. **「我在賣哪一層？」** 先確認自己的生意在河流的哪一段，才知道對手跟成本長什麼樣。
2. **「我的成本被誰主宰？」** 如果你在應用層，你的毛利綁在 API 計價與推理成本上；如果你在實驗室，你的成本綁在 GPU 取得上。
3. **「上游會不會吃掉我？」** 雲端廠一路往下做整合，純應用玩家必須靠「場景與資料」築自己的護城河。

#### Q: 依 AI 產業價值鏈的架構，為什麼「上游（晶片、雲端）」的利潤結構通常比「下游（應用）」更穩？

* 因為下游完全沒有利潤

* 因為上游賣的是不可替代的稀缺資源，且價格與需求確定性較高

* 因為上游的成本幾乎為零

* 因為下游根本不收費

> 💡 上游（晶片、雲端）提供的是所有人都需要的基礎設施，需求確定、競爭格局集中、定價權較強；下游必須靠具體應用場景證明省錢或增量，毛利好壞天差地別。
