# 主要玩家地圖

> 📅 2026-08-04 · 核心概念
> 晶片、雲端、實驗室、開放權重——每一層都是少數幾家在交手。看懂誰跟誰站在同一條戰線、誰跟誰是直接對手，就是看懂 AI 政治的起點。

---

上一篇文章把 AI 產業拆成價值鏈，這篇把名字填進去。好消息是：**每一層的玩家都少到可以背起來**。晶片層幾乎是輝達一家獨大，雲端層是三家巨頭，模型層是幾個實驗室加一群開放權重玩家。

看懂「誰跟誰在同一個方框裡」，比追蹤個別新聞重要得多——因為這個產業的競爭，很少是單點對決，多半是「陣營」對「陣營」。

## 先記一張鳥瞰圖

這張表就是整場棋局的地圖。橫向看是層級，縱向看是每個位置上的主要名字：

| 層級 | 主要玩家 | 開放/封閉 | 跟誰競爭 |
|---|---|---|---|
| **晶片 / GPU** | NVIDIA（近乎獨占）、AMD、Cerebras | 封閉 | 對「替代運算」的戰爭（自研晶片、雲端自己設計） |
| **雲端 / 運算** | AWS、Azure、GCP | 封閉 | 三家彼此競爭 + 各自往模型層整合 |
| **旗艦模型實驗室** | OpenAI、Anthropic、Google、DeepSeek | 封閉（DeepSeek 混開放） | 彼此正面對決，也各自與雲端結盟 |
| **開放權重** | Meta（Llama）、Qwen（阿里）、Mistral、DeepSeek | 開放 | 對抗「封閉 API 依賴」，也彼此在榜單上較量 |
| **應用 / 平台** | 各 SaaS、代理平台、辦公套件 | 混合 | 誰能把模型變成有人付費的產品 |

## 晶片層：一個人吃肉

輝達（NVIDIA）是這個產業最罕見的位置——**需求確定、技術領先、生態綁定**。

* 它是「賣鏟子之王」：從訓練到推理，全世界的算力需求幾乎都要先經它一手。
* 它的護城河不只是晶片，還有 **CUDA**：整個 AI 軟體堆疊長在它的生態上，換平台的成本極高。
* 挑戰者分兩路：**硬體派**（AMD、Cerebras、自研晶片的 Google TPU）與**替代派**（雲端自己設計晶片、或靠軟體把模型壓縮到小硬體上，見 `train-01-pretraining` 提到的大算力門檻）。

目前輝達仍吃肉，但「唯它不可」的光環正被一點點撬動。

## 雲端層：三巨頭的整合遊戲

AWS、Azure、GCP 表面上賣「GPU 小時」，實際上在打一場**「誰的套餐最完整」**的仗：

* 三家用資本把數萬張 GPU 組成叢集，附網路、儲存、安全、資料庫——單買晶片養不起這種規模。
* 它們全都往模型層整合：開自家實驗室（GCP → Google Gemini）、投資別家（Azure → OpenAI、AWS → Anthropic），把「雲端 + 模型 + API」綁進同一張帳單。
* 雲端之間的戰爭從「CPU 運算」變成「誰綁到最強的模型」。

> 要記住的一件事：雲端廠不是「算力房東」而已，它們是「整合者」。誰握有最強模型與最便宜推理，誰就能把整個企業的雲帳單整碗捧走。

## 模型層：實驗室 vs 實驗室

OpenAI、Anthropic、Google、DeepSeek 在正面對決。它不像晶片層「一家獨大」，而是**每幾個月換一次龍頭**：

* **OpenAI**：先發者光環，生態與產品化最完整（ChatGPT 就是最大的應用）。
* **Anthropic**：強調安全與工程品質，Claude 在寫程式與長文上口碑強。
* **Google**：自帶「模型 + 雲端 + 端點（搜尋、Android）」的縱向腹地，Gemini 藏在自家生態裡。
* **DeepSeek**：以極低成本煉出逼近旗艦的模型，是「開放權重浪潮」的代表，也讓「燒錢煉模型」的帳單受到挑戰。

實驗室的競爭焦點是**「下一個世代的模型要花多少錢才追得上」**——這直接連到 `econ-01-inference-cost`。

## 開放權重陣營：另闢一條戰線

Meta（Llama）、阿里（Qwen）、Mistral、DeepSeek 代表另一條路線：**不靠 API 綁定，靠把權重交給你。** 想深入了解開放與封閉的本質差異，回到 `models-01-open-vs-closed`。

* 它們彼此也在榜單上較量，但更大的對手是「封閉 API 依賴」這個概念本身。
* 開放權重壓低了「煉模型」的進入門檻：任何人下載權重自架，就能繞開 API 計價（`local-ai` 的主場）。
* 這股力量也在逼實驗室調整策略：要嘛把開放模型用於「餵自家 API 的流量入口」，要嘛靠「更強的旗艦 + 更好用的產品」拉開差距。

## 誰在跟誰「站同一邊」

真正的 AI 政治，是**陣營對陣營**：

```text
封閉整合派： 雲端(三巨頭) 結盟 旗艦實驗室(OpenAI/Anthropic/Google)
賣「開箱即用 + 最強能力 + 完整套件」
開放自架派： Meta/Qwen/Mistral/DeepSeek + 開發者社群
賣「可下載權重 + 隱私 + 成本可控」
算力上游：   NVIDIA 對兩派都賣，但握有最大議價權
```

## 每個玩家的主要賭注

看名字不夠，要看**「每家壓了什麼注」**。這決定它接下來的動作，也決定你該怎麼預期它：

| 玩家 | 主要賭注 | 若賭錯 |
|---|---|---|
| **NVIDIA** | AI 算力需求持續飆升、CUDA 生態難以撼動 | 自研晶片＋軟體壓縮讓「唯它不可」鬆動 |
| **AWS / Azure / GCP** | 綁定旗艦模型 → 企業整套雲帳單 | 模型品質落後，客戶轉去別朵雲 |
| **OpenAI** | 「先發＋產品化」的規模護城河 | 開放模型逼近，差異化被稀釋 |
| **Anthropic** | 品質與安全口碑，深耕開發者與企業 | 應用被別家的模型直接抄走 |
| **Google** | 自家生態（搜尋、Android）全面內建模型 | 生態優勢蓋不住模型差距 |
| **Meta / Qwen / Mistral / DeepSeek** | 開放權重＋低成本，繞開 API 綁定 | 榜單落後，社群與商用都流失 |

## 依賴關係：誰踩在誰的肩膀上

把「誰需要誰」畫出來，比畫「誰打誰」更能看懂動向：

```text
NVIDIA  ←──── 每一家（雲端、實驗室）都需要它的晶片
  ↑               ↑
AWS ──→ OpenAI   GCP ──→ Google Gemini
  ↑               ↑
Azure ──→ OpenAI   AWS 投資 Anthropic
  ↑
模型實驗室 ──→ 需要雲端的算力與分發
  ↑
應用層 ──→ 需要 API 與模型的品質
```

注意兩個不對稱：

* **晶片是單向依賴**：所有人依賴 NVIDIA，NVIDIA 卻不依賴任何單一客戶——所以它握有最大的議價權。
* **實驗室與雲端是雙向依賴**：實驗室需要雲端的資本與算力，雲端需要實驗室的模型來吸客。這種「互相需要」正是結盟新聞滿天飛的原因。

## 為什麼「DeepSeek 現象」值得單獨看

DeepSeek 不只是「又多一家實驗室」。它代表兩件事：

1. **煉模型的成本假設被改寫**：它用低得多的成本逼近旗艦品質，質疑了「必須燒數億美元才能追上」這條公理。
2. **開放權重的加速器**：它的出現讓「自架頂級能力」從理論變成日常，逼封閉實驗室重新證明「API 的溢價」值得。

後續的成本數字，我們會在 `econ-01-inference-cost` 細算——但那篇文章的伏筆，其實在 DeepSeek 身上。

## 玩家之間的四種關係

兩個玩家放在同一張棋盤上，關係不只有「競爭」一種。實際上是四種，常常同時存在：

| 關係 | 例子 | 關鍵訊號 |
|---|---|---|
| **競爭** | OpenAI vs Anthropic、AWS vs Azure | 榜單、客戶爭奪、降價 |
| **客戶 / 供應商** | 實驗室向雲端租 GPU、應用向 API 付費 | 帳單流向、合約年限 |
| **投資 / 結盟** | Azure 投資 OpenAI、AWS 投資 Anthropic | 股權新聞、獨家分發 |
| **互為倚仗** | Google 同時是模型商也是雲端商 | 自家生態優先、捆綁銷售 |

看懂這四種關係，新聞就從「個別事件」變成「棋局動向」。例如「AWS 投資 Anthropic」不只是投資新聞——它同時是「AWS 對抗 Azure 綁定 OpenAI」的布局。

## 這張地圖怎麼用

* **找你的上游**：你的成本被誰定？在雲端層就在三巨頭之間比價；在推理層就要算 API 或自架的長期帳。
* **找你的對手**：如果你在做「包裝模型成產品」，你的對手不只是同類 SaaS，還有往上整合的模型實驗室本身。
* **追蹤陣營動向**：一則「雲端投資實驗室」的新聞，比十則模型新聞更能說明未來走向。

#### Q: 為什麼說「雲端廠是整合者」而非只是算力房東？

* 因為雲端廠不做模型

* 因為雲端廠同時綁定模型、雲端與 API，把整套服務塞進同一張帳單

* 因為雲端廠不賣儲存

* 因為雲端廠不收錢

> 💡 三大雲端廠開實驗室或投資實驗室，把「雲端 + 模型 + API」捆在一起銷售，客戶的整個雲帳單都被整碗捧走，所以它們是整合者，不只是算力房東。
