# 注意力機制：模型如何決定「誰該聽誰」

> 📅 2026-08-01 · 核心概念
> 用白話文拆解 self-attention：Q、K、V 三個向量如何讓每個詞參考整句話的上下文。

---

注意力機制（Attention）是現代大型語言模型（LLM）的核心。從 GPT 到 Claude，幾乎所有模型都把「注意力」當成處理語言的基本單元。這篇文章用白話文拆解它：先講它解決什麼問題，再一步步走過 Q / K / V 的計算，最後用一段可執行的程式碼把整個流程串起來。

## 注意力在解決什麼問題

### 一句話不只是單詞的串接

先想想「The cat sat on the mat」這句話。單獨看每個詞，「sat」只是一個動詞；但放在句子裡，你知道「sat」的主詞是「cat」，地點是「mat」。意思是靠詞與詞之間的關係浮現的。

傳統的迴圈神經網路（RNN）把句子當成一條流水線：一個詞接一個詞處理，前面的資訊要「背」到最後。句子一長，前面的詞就被稀釋掉了——這就是所謂的長距離依賴問題。

注意力的做法完全不同：它讓每個詞在處理的當下，**直接回頭參考句子裡的所有其他詞**，自己決定誰重要、誰不重要。

### 固定視窗 vs. 動態視窗

* **固定視窗（n-gram / 卷積）**：只看附近的幾個詞，視窗大小寫死。
* **動態視窗（注意力）**：每個詞自己決定要看誰、各看多少，長度不受限制。

這就是注意力的關鍵優勢：**每個詞都同時「看」整句話**，而且看得多專注是可以學出來的。

## 白話版流程：一場會議

把一句話想像成一場會議，每個詞是一個與會者。注意力就是會議的「溝通規則」：

### 步驟一：每個人準備三張卡片

每個詞用三組權重，把自己變成三個角色：

* **Q（Query，查詢）**：我想找誰？——我對誰感興趣。
* **K（Key，鑰匙）**：我是誰？——別人可以用它來認出我。
* **V（Value，內容）**：我有什麼可提供的？——我真正要傳遞的資訊。

### 步驟二：每個人向所有人發問

用「我的 Q」去比對「每個人的 K」，算一個相似度分數。分數越高，表示「你這個人越相關，我越該聽你的」。

### 步驟三：softmax 把分數變成權重

分數有正有負、大小不一，無法直接當權重用。`softmax` 把它們壓到 0 到 1 之間，而且總和等於 1——變成一個正式的「注意力分配」。

### 步驟四：加權總和

把每個詞的 V 依照權重加起來，得到這個位置新的向量。權重高的詞，貢獻就大。這個新向量就是「這個詞、吸收了全句上下文之後」的新表示。

## Q / K / V 到底是什麼

從矩陣的角度看，一切都很乾淨。設輸入為 $X$，形狀是 `(seq_len, d_model)`（詞數 × 向量維度）：

```python
import numpy as np

def softmax(x):
    x = x - x.max(axis=-1, keepdims=True)  # 數值穩定
    e = np.exp(x)
    return e / e.sum(axis=-1, keepdims=True)

def self_attention(X, Wq, Wk, Wv, d_k):
    # X: (seq_len, d_model)
    Q = X @ Wq           # (seq_len, d_k) 查詢
    K = X @ Wk           # (seq_len, d_k) 鑰匙
    V = X @ Wv           # (seq_len, d_k) 內容

    scores = Q @ K.T     # (seq_len, seq_len) 相似度
    scores = scores / np.sqrt(d_k)  # 縮放，穩定梯度
    weights = softmax(scores)       # 每列總和 = 1
    out = weights @ V    # (seq_len, d_k) 加權總和
    return out
```

其中 `Wq`、`Wk`、`Wv` 是模型在訓練時學出來的權重矩陣。輸入 X 的每個 token 都會被這三個矩陣投影成「查詢」、「鑰匙」、「內容」三種向量。

### 一圖勝千言

以三個詞為例，注意力權重矩陣大概是這個樣子（每一列是一個詞的注意力分配）：

```
        "the"   "cat"   "sat"
"the"  [ 0.98   0.01    0.01 ]
"cat"  [ 0.02   0.90    0.08 ]
"sat"  [ 0.01   0.15    0.84 ]
```

讀法：看「sat」那一列——它把 15% 的注意力給「cat」，84% 給自己。「cat」是它的主詞，所以它主要參考「cat」的內容。每一列加起來都是 1。

## 矩陣形狀一覽

| 張量 | 形狀 | 意義 |
|------|------|------|
| X | (seq_len, d_model) | 輸入詞向量 |
| Q、K | (seq_len, d_k) | 查詢與鑰匙 |
| V | (seq_len, d_v) | 內容向量 |
| scores | (seq_len, seq_len) | 每對詞的相似度 |
| weights | (seq_len, seq_len) | softmax 後的注意力分配 |
| output | (seq_len, d_v) | 上下文感知的新表示 |

實際模型中通常 `d_model = 768 ~ 12288`，`d_k = d_v = d_model / num_heads`。

## 為什麼要除以 √d_k

`Q @ K.T` 的結果是 d_k 個數字的內積。維度越高，內積的數值越大，softmax 會迅速「飽和」到接近 one-hot——梯度就消失了。除以 `√d_k` 讓分數維持在合理的尺度，是注意力得以穩定訓練的關鍵細節。

## 從單頭到多頭注意力

真實模型用的幾乎都是**多頭注意力（Multi-Head Attention）**：把 Q / K / V 切成好幾組，每組獨立做一次注意力，再把結果拼起來。

這像是同時開好幾場小組會議，每場會議各自注意不同的面向：

* 某一頭學會注意語法依賴（「sat」→「cat」）
* 某一頭學會注意指代關係（「it」→「the cat」）
* 某一頭學會注意位置關係或特殊標記

多頭讓模型能同時捕捉多種不同的關係，而不是只能用一種方式分配注意力。

## 這對 LLM 為什麼重要

* **雙向理解**：每個詞都能參考左邊和右邊的詞，意思判定更準。
* **長上下文**：注意力沒有固定距離上限，理論上 10 萬字的上下文每個位置都能參考任何其他位置（代價是計算量隨長度平方成長）。
* **可疊加**：Transformer 把注意力層疊個幾十層，每一層都在「重新詮釋」前一次的表示，模型的深度由此而來。
* **推論的本質**：生成下一個 token 時，模型做的就是對已有的全部 token 再做一次注意力，然後預測最可能的接續。

## 總結

| 概念 | 一句話 |
|------|--------|
| 注意力 | 每個詞依「相關性」參考其他所有詞 |
| Query | 「我想找誰」 |
| Key | 「我是誰，方便被找到」 |
| Value | 「我實際提供的內容」 |
| Softmax | 把分數變成總和為 1 的權重 |
| 多頭注意力 | 多場平行小組會議，各自注意不同面向 |

注意力不是魔法——它是一套非常明確的矩陣運算：**查詢 × 鑰匙 → 分數 → softmax → 權重 → 加權取內容**。理解了這五步，你就理解了 Transformer 的心臟。
