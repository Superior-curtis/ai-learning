# 預訓練：讀完整個網際網路

> 📅 2026-08-04 · 核心概念
> 模型「學會」的那一天，其實是幾百 TB 文字、數千張 GPU、連續好幾個月在跑同一個『猜下一個詞』的任務。這就是預訓練。

---

`llmcore-01` 說，LLM 的本質是「猜下一個詞的機器」。那這台機器是怎麼被教出來的？答案就是**預訓練（pre-training）**：拿整個網際網路等級的資料，在數千張 GPU 上跑同一個任務，連續好幾個月。

預訓練是一切現代模型的起點。它決定模型「懂多少語言、多少世界知識」，也決定誰玩得起、誰玩不起這個遊戲。

## 預訓練在做什麼

一句話：**把「猜下一個詞」這個任務，餵給一整個網際網路的文字，反覆練習億萬次。**

```text
[文章、書、程式碼、對話…]
        ↓ 切成 token
[一個一個 token 的序列]
        ↓ 對每個位置
蓋住下一個 token → 模型猜 → 對答案 → 調整權重
        ↓ 重複
數千張 GPU × 數個月 × 兆級 token
```

過程細節在 `llmcore-01` 已經講過（餵一句、猜下一個、算誤差、調參數）。預訓練的特點是**規模**：資料以百萬億 token 計，參數以百億、千億計，硬體以「一張數萬美元的 GPU × 幾千張」計。

## 規模大到難以想像

用三個數字感受一下：

| 資源 | 量級 |
|---|---|
| 訓練資料 | 幾十萬億 token（一個 token 約半個中文字） |
| 模型參數 | 數百億～數兆個參數 |
| 計算量 | 數十萬到數百萬 GPU 小時 |
| 成本 | 數百萬到數億美元 |

> 預訓練是「富人的遊戲」：一次完整預訓練的帳單，超過絕大多數公司的全年預算。這也解釋了為什麼世界上能從零訓練大模型的公司，一隻手數得完。

## 預訓練教會了什麼

把「猜下一個詞」練到極致，會**順便**獲得三樣東西：

1. **語言能力**——文法、句法、用詞，全都內化。
2. **世界知識**——「巴黎在法國」「光合作用」這些，都被壓縮在參數裡。
3. **推論雛形**——因為文字裡有大量「因為所以」「如果則」，模型學會了沿著邏輯接續。

重點：**這些都不是被「教」的，而是「猜詞」任務逼出來的副產品。** 你沒有直接告訴它「法國的首都是巴黎」，但為了猜對那句，它必須把這個關係存進參數。

## 預訓練 ≠ 學會你想要的

預訓練做完的模型，只會一件事：**流利地接續文字。** 它不會乖乖回答你的問題、不會遵守「用 JSON 回覆」、也不懂「你是客服」。它像一個滿肚子知識、但不聽話的天才。

之後要靠兩件事把它變成「能用的產品」：

* **微調（fine-tuning）**：教它「聽話」和「專精」——下一篇文章 `train-02-finetuning`。
* **RLHF（人類回饋對齊）**：教它「符合人類偏好」——`train-03-rlhf`。

## 為什麼你「不需要」自己預訓練

你幾乎永遠不需要自己跑預訓練。理由很實際：

* **太貴**：一次完整預訓練的帳單是天文數字。
* **有現成的**：開放模型（Llama、Mistral、Qwen…）把預訓練好的權重直接開放下載。
* **微調便宜幾個數量級**：在你自己的資料上微調，成本可能是預訓練的百萬分之一。

所以對 99% 的人來說，**「用模型」= 下載或呼叫已預訓練的模型**；「訓練」= 在它上面做**微調**，而不是從零預訓練。

#### 決定需求

是要開箱即用（呼叫 API）？要特化（微調）？還是（幾乎不會）從零預訓練？

#### 挑一個已預訓練的模型

開放模型下載權重，商業模型用 API。不要自己從零開始。

#### 要特化才微調

有固定技能/風格需求時，才在它之上做微調（見 train-02）。

#### 其餘用提示詞／RAG

九成需求靠提示工程與 RAG 就能解決，不必動模型權重。

> 一句話記住預訓練的位置：它是模型的「基礎教育」，花費最高、只有少數玩家參與；而你站在這個基礎之上，用更便宜的微調與提示詞來打造自己的產品。

## 損失曲線：怎麼知道它在「變好」

預訓練的「分數」叫**困惑度（perplexity，PPL）**——大致是「模型每次猜詞，平均對幾個候選猶豫」。PPL 越低，代表它「越是能鎖定正確的下一個詞」，也就是對語言掌握得越好。

```概念：PPL&#x20;越低越好
# perplexity ≈ exp(平均 log 機率)。越低 = 對下一個詞越篤定
# 好模型（低 PPL）  ：見「AI moves ____」→ fast 機率 0.9
# 差模型（高 PPL）  ：每個候選都差不多，像在擲骰子

# 訓練時，每天看 PPL 下降 = 模型在進步
# 1000 步: PPL 8.4
# 10000 步: PPL 4.1
# 100000 步: PPL 2.3  ← 越來越會「猜」
```

## 這篇文章的意義

預訓練回答的是「模型怎麼會說話」這個問題。它同時埋下兩個伏筆：**預訓練很貴，但微調很便宜**（下一篇），以及**模型只是學會接話，還沒學會聽話**（RLHF，`train-03-rlhf`）。

#### Q: 為什麼「從零預訓練一個大模型」對絕大多數人來說不是正確選擇？

* 因為預訓練的模型品質比較差

* 因為預訓練成本極高，且有現成的開放模型或 API 可用

* 因為預訓練無法處理中文

* 因為預訓練需要很強的程式能力

> 💡 一次完整預訓練要花數百萬到數億美元，且開放模型與商業 API 早就把預訓練好的權重給你了。對 99% 的人，正確路徑是「用現成模型 + 微調 + 提示詞」。
