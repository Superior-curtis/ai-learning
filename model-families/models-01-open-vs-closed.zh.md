# 開放 vs 封閉模型

> 📅 2026-08-04 · 核心概念
> Llama 能下載、GPT 只能用 API——這不只是『免費 vs 付費』，而是『你控制什麼、誰控制什麼』的根本選擇。

---

打開任何 AI 論壇，第一個要搞清楚的不是「哪個模型最強」，而是**「這個模型是開放的還是封閉的」**。它決定了你能拿模型做什麼、模型被誰控制、以及你踩進的是哪個授權迷宮。

## 光譜，不是二分

其實「開放」不是一個開關，是一條光譜：

```
完全封閉            開放權重             真正開源（極少）
GPT / Claude       Llama / Mistral     開放權重＋
(只給 API)         / Qwen              資料與訓練流程
```

| 類型 | 例子 | 你能拿到 |
|---|---|---|
| **封閉（API）** | GPT、Claude、Gemini、Gemini | 只能透過 API 呼叫 |
| **開放權重** | Llama、Mistral、Qwen、DeepSeek | 下載權重，自己架 |
| **完全開源** | 一些研究模型 | 權重＋資料＋訓練細節（極少） |

## 最常被誤解的：開放權重 ≠ 開放原始碼

「開放權重（open-weight）」指的是**你把訓練完的數字（權重）下載回去**。但：

* **你可能看不到訓練資料。**
* **授權常有使用限制**（例如 Llama 對每月活躍用戶超門檻的商用需另行授權）。
* 你拿到的是「成品」，不是「食譜」。

所以別把「開源」兩個字想太滿。業界現在更愛用**「開放權重」**這個更誠實的詞。

## 封閉模型的勝場

為什麼那麼多人用貴的封閉 API？

* **品質通常領先**：旗艦封閉模型往往在最強排行榜頂端（尤其推理、長文）。
* **維護與安全幫你扛**：修 bug、對齊、安全更新都算在服務裡。
* **省心**：不用管 GPU、部署、升級——呼叫即用。
* **高階功能**：有些功能只給自家 API（如某些工具、多模態服務）。

## 開放權重的勝場

那為什麼開源社群如此熱血？

* **隱私與合規**：資料不出自己的伺服器；法規敏感（醫療、金融）幾乎只能自架。
* **成本可預期**：算一次折舊成本，不受「每 token 計價」與漲價影響。
* **控制權**：你可以改、微調（`train-02`）、審計，不受供應商政策牽制。
* **離線**：沒網路也能跑（`local-ai` 的主場）。

#### 對照 / Comparison

## 怎麼選：一張決策表

| 你的情境 | 較適合 |
|---|---|
| 做產品要最快的 SOTA | 封閉（API） |
| 處理病歷、合約、內部機密 | 開放權重（自架） |
| 成本敏感、量大到計費嚇人 | 開放權重（或先算帳再決定） |
| 要隨時調用、不想碰運維 | 封閉（API） |
| 研究／教學／離線開發 | 開放權重 |

> 實務鐵律：「開放或封閉」先於「哪個型號」。 對不碰敏感資料、要最強能力的團隊，封閉 API 是默認；對隱私/成本/控制敏感的，開放權重是主場。也可以混用——敏感部分自架、爽快的部分走 API。

## 這不是永恆的分界

市場在變：開放模型（DeepSeek、Qwen）逐年逼近封閉旗艦；封閉公司也釋出權重（如部分模型）。**別把「開放勝」「封閉勝」當信仰**，而是每年重新評估一次：你的需求對應的光譜位置。

#### Q: 「開放權重」與「開源」最大的差別是什麼？

* 開放權重比較弱

* 開放權重給你可下載的權重，但通常不公開訓練資料、且有授權限制

* 開放權重是免費的，開源要付費

* 兩者完全一樣

> 💡 開放權重＝你能下載權重自架，但『權重』只是成品，訓練資料往往不公開、授權也常有商用門檻。它是『拿到模型』，不是『拿到食譜』。
