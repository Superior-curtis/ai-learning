# 主要模型家族導覽：GPT、Claude、Llama…

> 📅 2026-08-04 · 核心概念
> GPT、Claude、Llama、Gemini、Mistral、Qwen——六大家族的出身、開放程度與擅長，一篇文章帶你逛完。

---

上一篇把模型分成「開放 vs 封閉」（`models-01-open-vs-closed`）。現在去逛「店面」：這些模型到底是誰做的、各自擅長什麼。

先講清楚：**這篇文章是「快照」，不是「永恆真理」。** AI 界半年就可能換一輪霸主。讀法是把「家族」當成心智分類，把「具體型號」當成隨時要更新的資料。

## 六大家族一覽

| 家族 | 公司 | 開放程度 | 一句話印象 |
|---|---|---|---|
| **GPT** | OpenAI | 封閉（API） | 開創者；生態最大、工具最齊 |
| **Claude** | Anthropic | 封閉（API） | 注重安全對齊；長文與寫作強 |
| **Gemini** | Google | 封閉為主 | 與 Google 產品深度整合；多模態起家 |
| **Llama** | Meta | 開放權重 | 開源社群的地基 |
| **Mistral** | Mistral AI（法國） | 開放+閉合 | 高效小模型、歐系風格 |
| **Qwen** | 阿里巴巴 | 開放權重 | 中文語系極強、全能 |

另外常被提起的還有 **DeepSeek**（開放權重、成本極低）、**Grok**（xAI，與 X 整合）、**Gemma**（Google 的開放小模型）等。重點不是背清單，而是理解「各有擅場」。

## GPT：開創者，生態之王

* **來歷**：2022 年底的 ChatGPT 把 LLM 帶進大眾視野，「GPT」幾乎成了「AI 助手」的代名詞。
* **強項**：生態最成熟——外掛、函式呼叫、多模態、Codex 代理，工具最齊；使用者最多，回饋資料最肥。
* **性格**：全面、穩、開箱即用的「預設選項」。

## Claude：以「對齊」為賣點

* **來歷**：Anthropic，由 OpenAI 前高層創立，把安全對齊當品牌核心（見 `train-03-rlhf`）。
* **強項**：在「有用、誠實、無害」上的打磨很出名；長文理解、寫作、程式碼都屬第一梯隊。
* **性格**：謹慎、說話有分寸、適合「要讓它乖乖幹活」的工作流。Claude Code 就是它的終端代理（全書 `claude-code` 系列的主角）。

## Gemini：Google 的整合機器

* **來歷**：Google DeepMind 出品，打從一開始就強調**多模態**（原生影像、影片、音訊理解）。
* **強項**：與 Google 產品（搜尋、Workspace、Android）深度綁定；多模態是天生優勢。
* **性格**：你會「在 Google 全家桶裡遇到它」，而不是特別去「選它」。

## Llama：開源社群的地基

* **來歷**：Meta 開源權重，讓「自架模型」成為可能。
* **強項**：不是「最強」，但「被改最多」——社群在上面做微調、蒸餾、本地化，衍生模型多到數不清。
* **性格**：它更像是「樂高積木的母模」，而不是一個「終端產品」。

> 記住一個模式：封閉家族（GPT / Claude / Gemini）比的是「產品完成度」；開放家族（Llama / Qwen / Mistral）比的是「可塑性」。 一個讓你少操心，一個讓你多動手。

## Mistral 與 Qwen：兩種「開放」的路線

* **Mistral**（法國）：以「小模型高效率」聞名——用更少的參數達到接近大模型的表現，很受歐洲與本地部署圈喜愛。
* **Qwen**（阿里巴巴）：中文能力尤其突出，參數規模從 tiny 到旗艦都有，是中文開源圈的主力。

## 怎麼看待「誰最強」

排行榜（`models-06-evaluation`）每天都在變。更持久的判斷方式有三招：

1. **對齊你的任務**：寫長文？Claude 強。寫程式？GPT/Claude 都強。中文？Qwen 穩。多模態？Gemini 天生。
2. **看實測不看行銷**：用你自己的測試集（幾十條你的真實任務），讓各家跑一輪比較——比任何排行榜都準。
3. **承認有偏好**：模型「性格」會影響你的工作流（謹慎 vs 敢衝），選你「合得來」的。

```一個自己跑比較的開場
# 別只信排行榜——用你自己的 20 題，讓各家 API 跑一次
tasks = ["用三句解釋微積分給高中生",
       "把這段契約改成更白話",
       "寫一個 Python 函式做資料清理"]

for provider in ["openai", "anthropic", "google"]:
  for task in tasks:
      # 呼叫各家 SDK，收集回覆
      ...
# 然後（重點）人肉打分：哪個比較「合你需求」
```

## 一句話總結

沒有「最好的模型」，只有「適合你任務與情境的模型」。把家族當心智地圖、把型號當會變的資料，你就永遠不會被排行榜綁架。
