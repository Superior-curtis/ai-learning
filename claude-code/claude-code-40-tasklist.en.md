## TaskListTool: Listing Tasks

TaskListTool lets the model see again "what tasks exist right now, who is blocking whom, and what still isn't done." In multi-step workflows, it serves as the **overview panel for the task system**.

### One-Sentence Summary

> TaskListTool gives Claude Code the ability to **"look up and see the whole picture"** within complex task flows.
