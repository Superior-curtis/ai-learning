## Claude Code 快速上手

### 適合誰讀

你已經有 terminal 基礎，想把 AI 真正整合到本地開發流程中。你希望 AI 不只是「寫幾行程式」，而是能真正幫你推進任務、讀取專案、修改程式碼、執行指令並驗證結果。

***

### 安裝

```bash
npm install -g @anthropic-ai/claude-code
```

安裝後確認版本：

```bash
claude --version
```

第一次使用需要登入你的 Claude 帳號：

```bash
claude
```

Claude Code 會引導你完成授權流程。

***

### 核心觀念：先在正確的目錄工作

Claude Code 不是一個脫離專案上下文的聊天框。它會直接讀取你當前目錄的程式碼和檔案結構。

**基本原則：**

* 進入專案目錄再啟動 Claude Code
* 不要在桌面、下載目錄等雜亂的目錄直接開幹
* 如果你還沒有專案，先建立一個空目錄，再讓 Claude Code 開始工作

***

### 新手最佳實踐：三明治協作節奏

Claude Code 最適合的工作節奏：

```
理解 → 規劃 → 執行
```

#### 步驟 1：先讓它理解專案

```
先幫我看看這個專案的整體結構。
告訴我主要目錄是做什麼的，首頁相關程式碼大概在哪些檔案裡。
先不要改程式碼。
```

#### 步驟 2：要求方案

```
我要給首頁加一個輪播圖。
先給我一個實作方案，告訴我準備修改哪些檔案、怎麼改。
先不要執行。
```

#### 步驟 3：確認後再執行

```
可以開始改。
改完以後請執行建置檢查，並告訴我改了哪些檔案。
```

***

### 從零建立新專案

想讓 Claude Code 幫你建立一個新專案時：

```
我現在在一個空目錄裡，想從零建立一個 Next.js + TypeScript 專案。

先告訴我你建議的初始化方式：
- 準備使用什麼腳手架
- 會安裝哪些依賴
- 會產生哪些關鍵目錄

先不要執行。

確認後，再開始建立專案。
建立完成後，請啟動專案並告訴我是否執行成功。
```

**不要在一句話裡混雜「建立專案」和「開發功能」。**

***

### 常見新手錯誤

| 錯誤 | 正確做法 |
|------|----------|
| 在桌面或下載目錄啟動 | 先 cd 到專案目錄 |
| 一句話說「幫我做個專案」 | 說清楚技術棧：Next.js + TypeScript |
| 沒有說「先不要改程式碼」 | 先分析 → 再方案 → 最後執行 |
| 只看「它有沒有改完」不看錯誤訊息 | 一定要看建置結果 |
