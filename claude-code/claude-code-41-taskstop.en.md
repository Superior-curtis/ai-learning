## TaskStopTool: Stopping Tasks

TaskStopTool has a clear goal: stop a background task that is currently running. It typically targets two kinds of sources: background shells launched by BashTool, and background agents launched by AgentTool.

### One-Sentence Summary

> TaskStopTool adds the **"interrupt" capability** to Claude Code's background execution chain — an indispensable piece of the formal task system.
