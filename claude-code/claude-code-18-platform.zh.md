## 插件、Skills 與 Agent：Claude Code 如何走向平台化

如果 Claude Code 只依靠官方內建能力，那它最多是一個很強的產品。但從原始碼目錄看，它已經在向另一個方向演化：**平台化**。

最明顯的訊號有三類：

🧩
插件系統
新增命令 / 能力 / 整合📚
Skills 系統
新增知識 / 流程 / 約束👥
Agent / Team
新增協作 / 分工 / 子任務

***

### 三者不是並列替代關係

它們解決的問題完全不一樣：

🧩
插件

Agent

### 為什麼說是平台化？

判斷一個系統是不是平台化，關鍵不在於功能多不多，而在於：

能力能不能被擴展？→ 插件經驗能不能被複用？→ Skills任務能不能被分派？→ Agent外部生態能不能接入？→ MCP

***

### 一句話總結
