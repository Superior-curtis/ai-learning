## SendMessageTool：Agent 通訊

在多 Agent 體系裡，普通文字不會自動被其他 teammate 看見。如果一個 Agent 想通知另一個 Agent、廣播訊息、回覆審批，它必須走 **SendMessageTool**。這是多 Agent 系統真正成立的基本建設。

### 一句話總結

> SendMessageTool 把多 Agent 協作裡的**訊息傳遞做成了正式協定**，而不是靠模型輸出文字碰運氣。
