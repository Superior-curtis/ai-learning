## 一次任務的內幕

Claude Code 接住你的需求後，內部會走一條固定的迴圈。下面是簡化的五步流程：

```text
使用者輸入 → 上下文組裝 → 模型呼叫 → 工具執行 → 觀察回饋
↑___________________________↓
```

想更深入了解，去看 [模擬器頁面](/simulator)，可以點擊每一步查看真正的 prompt 與 payload。

## 你的第一個任務

來試試看吧。開一個空目錄，然後貼上這段指令：

```bash
cd ~/playground
mkdir -p first-project && cd first-project
claude
```

接著在 Claude Code 裡輸入：

```
我現在在一個空目錄裡，想從零建立一個 Next.js + TypeScript 專案。
先告訴我你建議的初始化方式，先不要執行。
```

> 小技巧： 每次都讓 Claude Code「先說方案、確認後再執行」。這是新手最重要的習慣。

## 檢查你的理解

#### Q: Claude Code 最適合的工作節奏是哪一種？

* 直接講需求，馬上讓它動手

* 理解 → 規劃 → 執行，分三步走

* 一次丟進一整包需求，讓它自己拆

* 完全不用 terminal

> 💡 三明治節奏（理解 → 規劃 → 執行）能大幅減少返工。先讓它讀懂專案、再要方案、最後才執行。
