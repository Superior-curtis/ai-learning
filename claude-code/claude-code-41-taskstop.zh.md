## TaskStopTool：停止任務

TaskStopTool 的目標很明確：停止一個正在運行的後台任務。通常對應兩類來源：BashTool 啟動的後台 shell、AgentTool 啟動的後台 agent。

### 一句話總結

> TaskStopTool 給 Claude Code 的後台執行鏈補上了**「中斷」能力**——這是正式任務系統不可缺的一環。
