# 什麼是 AI：一份白話地圖

> 📅 2026-08-04 · 使用教學
> AI、機器學習、深度學習、LLM——這些詞到底是什麼關係？這篇文章用一張「蛋糕圖」幫你把迷宮一次理清。

---

「AI」可能是當今被濫用最嚴重的詞。新聞說「AI 取代工作」，客服說「AI 助理為您服務」，你手機相簿也說「AI 自動分類」。但這些「AI」指的根本不是同一件事。

這篇文章是整本書的入口。它不做數學，只幫你建立一張**能看懂全局的地圖**：AI 到底是什麼、AI／機器學習／深度學習／LLM 這幾個詞是什麼關係、以及今天的 AI 到底「懂」還是「不懂」。

## AI 是什麼

最樸素的定義：**AI = 讓機器去做「本來需要人類智慧才能做的事」。**

本來的定義很廣——下棋、認圖片、翻譯、開車、寫詩，都算。但「AI」這個詞用久了，目前幾乎等同於一種特定路線：**用大量資料＋大量計算，讓程式自己「學」出能力**，而不是人類一條一條把規則寫死。

換句話說，今天的 AI 幾乎都是一個用於當代的核心詞：**它是「程式自己學會」，不是「程式被寫好」。**

## 一張蛋糕圖：四個詞的關係

最常被混用的四個詞，其實是四層俄羅斯娃娃：

```
        ┌─────────────────────────────────┐
        │               AI                │  最廣：任何機器做的「智慧任務」
        │   ┌───────────────────────────┐ │
        │   │    Machine Learning       │ │  讓程式從資料中「學」
        │   │   ┌─────────────────────┐ │ │
        │   │   │  Deep Learning      │ │ │  用多層神經網路學
        │   │   │ ┌─────────────────┐ │ │ │
        │   │   │ │      LLM        │ │ │ │  大型語言模型（近年主角）
        │   │   │ └─────────────────┘ │ │ │
        │   │   └─────────────────────┘ │ │
        │   └───────────────────────────┘ │
        └─────────────────────────────────┘
```

```一句話版
AI          機器做「需要智慧的任務」
└─ ML      其中一種做法：從資料學規律
    └─ DL  其中一種技法：用多層神經網路
        └─ LLM  目前最紅的神經網路模型：專精於語言
```

> 關鍵是歸屬關係，不是等號：所有 LLM 都是 DL，所有 DL 都是 ML，所有 ML 都是 AI——但反過來不一定成立。「AI 電影海報」不是 LLM，「房價預測的線性迴歸」不是 DL。

## 逐層拆開

**AI（Artificial Intelligence）** —— 最外層。一切讓機器做智慧任務的統稱。1950 年代的西洋棋程式是 AI，今天的大語言模型也是 AI。

**ML（Machine Learning，機器學習）** —— 里程碑：不寫死規則，而是**餵大量範例，讓程式自己學出規律**。垃圾郵件過濾、房價預測、推薦系統，都曾是 ML 的明星應用。

**DL（Deep Learning，深度學習）** —— ML 的其中一種熱門技法，用很多層的神經網路（「深」）。它之所以稱霸，是因為在圖像、語音、語言這些**複雜且不規則**的資料上，表現碾壓傳統 ML。今天幾乎所有 SOTA 模型都是 DL。

**LLM（Large Language Model，大型語言模型）** —— DL 家族裡最出圈的一員，代表作是 GPT、Claude、Llama。它「大」（參數動輒幾百億以上），專精語言。它的整個運作，就是我們第一篇講的「猜下一個詞」（`llmcore-01-next-token`）。

## 生成式 AI 又從哪冒出來

你可能還遇過 **Generative AI（生成式 AI）**這個詞。它不是另一層，而是**一種能力分類**：強調「模型能**生成**新內容」——寫字（LLM）、畫圖（擴散模型）、做音樂，而不是只會分類／預測。市面上九成的「AI 產品」講的都是生成式 AI。

```
判別式 AI（Discriminative）：只判斷——這是貓還是狗、這是垃圾郵件嗎。
生成式 AI（Generative）   ：產生——寫一篇文章、畫一張圖、做一段音樂。
```

## 今天的 AI「懂」還是「不懂」

這個問題值得一次講清楚，因為它決定了你該多信任 AI。

* **它不「懂」。** LLM 內部只是一堆參數在算「哪個詞最可能接下去」的機率。它沒有意識、沒有理解、不會「想」。
* **但它表現得像是懂了。** 因為語言是壓縮的知識（`llmcore-01`），它把全世界表達過的模式都「背」成了統計規律。
* **所以它「看起來懂」卻會一本正經胡說八道。** 它分不清「這個詞很順」和「這個事實正確」。這在 `llmcore-05-hallucination` 會詳談。

```text
一個 AI 助理的「思考」其實是：
[你輸入的問題] → 在參數裡算「最可能的下一個詞」 → 吐一個詞
↑
這裡沒有「懂只懂哪個詞最順」，沒有理解燈泡
```

## 你早已在用它

你以為 AI 離你很遠，其實你天天在用：

| 你做的事 | 背後的 AI |
|---|---|
| 手機相簿自動分類照片 | 電腦視覺（DL） |
| 打字的自動選字、校正 | 語言模型（小號） |
| YouTube / 網購推薦 | ML 推薦系統 |
| 語音助理回你話 | 語音辨識 + LLM |
| 翻譯 App | 神經機器翻譯 |
| ChatGPT / Claude 寫給你看 | 大型語言模型 |

## 一張地圖長這樣

把這本書比喻成一個搜尋框架：看懂 AI 產業，就是看懂這幾層怎麼黏在一起——從**它是什麼**（本篇）→ **它怎麼運作**（Part 1）→ **怎麼用它做產品**（Part 2）→ **用什麼工具**（Part 3）→ **這是門什麼生意**（Part 4）→ **該怎麼負責地看待它**（Part 5）。

而這趟旅程最值得先記住的，是這四層蛋糕圖——之後每一章，你都站得穩。

#### Q: 「所有 LLM 都是 AI，但所有 AI 不都是 LLM」——這句對嗎？

* 對，因為 LLM 是 AI 的一種特例，不是反過來

* 不對，AI 和 LLM 是同一件事

* 對，因為 AI 比 LLM 小

* 不對，LLM 比 AI 大

> 💡 主語正確：LLM 是 DL、DL 是 ML、ML 是 AI，是「包含」不是「等於」。所以所有 LLM 都是 AI；但有大量 AI（如西洋棋程式、規則系統）根本不是 LLM。
