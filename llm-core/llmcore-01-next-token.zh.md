# 預測下一個詞：LLM 的核心把戲

> 📅 2026-08-04 · 核心概念
> 大型語言模型的本質，一句話就說得完：它是從它讀過的大量文字裡，學會「猜下一個詞」的機器。這篇文章把這句話拆開來講。

---

大型語言模型（LLM）看起來很神奇：它會寫文章、寫程式、回答問題、推理。但只要把這層魔力剝開，核心其實非常樸素——**LLM 做的唯一一件事，是預測下一個詞**。

不只「大部分時間」，而是**每一次輸出、每一個字**，都是靠同一個把戲產生的：看看目前為止的文字，然後猜「接下來最可能是哪一個詞」。這篇文章把這個把戲徹底拆開，因為看懂它，你就看懂了一半以上的 AI。

## 一句話的核心

> LLM = 一台**從大量文字中學會「猜下一個詞」**的機器。

三個關鍵詞，分別對應三個問題：

* **大量文字** —— 它學了什麼？（訓練資料）
* **學會** —— 它是怎麼學的？（訓練過程）
* **猜下一個詞** —— 它到底在做什麼？（推論/生成）

我們先從最後一個「猜下一個詞」開始，再回過頭補前面的兩塊。

## 「猜下一個詞」到底是什麼意思

想像一句話寫到一半：

```
AI moves ______
```

一個人填空時會想「下一個該填 fast、quickly 還是 forward？」，然後挑一個。LLM 做的幾乎就是這件事，差別在於兩點：

**第一，它不是挑一個詞，而是替「字典裡的每一個詞」算一個分數。**

模型內部會輸出一個清單：每個候選詞，都有一個「它是下一個詞」的機率。全部加起來等於 1。

```
AI moves ____
  fast     42%
  quickly  31%
  forward  11%
  慢慢地    9%
  ...
  (字典裡的其他 99,000 個詞，各一點點)
```

```text
使用者輸入 → 模型把上下文轉成「向量」
↓
對字典裡每個詞打一個分數 (logits)
↓
把分數轉成機率 (softmax)  →  每個詞各有多少 %
↓
從這個機率分布「抽」一個詞當答案
↓
把新詞接回去，再預測下一個…
```

**第二，它也不是真的「填空」——它是「抽籤」。**

模型拿到一張機率籤（42% fast、31% quickly…），然後按這個機率**隨機抽一個詞**。這就解釋了很多事情：

* 同一個問題問兩次，答案可能不同（每次抽籤結果不同）。
* 模型可以「調溫度」變得更保守或更大膽（這在 `llmcore-04-sampling` 會講）。

## 這份機率是從哪來的：訓練過的大數據

現在回答前面的問題：模型怎麼知道「fast」有 42%、「慢慢地」只有 9%？

答案很樸素：**它在讀過的大量文字裡，看過太多太多的「AI moves ____」和類似句子。**

想像你讀了整個網際網路——數百億句話。你的「直覺」裡會慢慢累積規律：

* 看到「AI moves」，你自然而然會接著想到 fast、quickly。
* 看到「The capital of France is ____」，你會想到 Paris。
* 看到「def main(): ____」，你會接著寫 pass 或 return。

訓練的過程，就是把「猜下一個詞」這件事，在網際網路上**反覆練習到極致**：

1. 抓來海量文字（文章、書、程式碼、對話）。
2. 每次都蓋住句子的下一個詞，讓模型猜。
3. 猜錯就調整模型裡幾百億個參數，讓它下次更準。
4. 重複幾兆次，直到模型對語言規律的掌握到了「內化」的程度。

#### 餵入一句話，蓋住下一個詞

「The cat sat on the ____」。模型只能看到前面，看不到答案「mat」。

#### 模型做出預測

模型根據前面的詞，給字典裡每個詞一個機率。

#### 對答案、算損失

跟真正的答案「mat」比：如果它把 1% 給 mat，就把誤差記下來。

#### 微調參數

用梯度下降稍微調整模型權重，讓「猜對的詞」下次機率更高。

#### 重複億萬次

在整個網際網路上反覆做，直到模型內化了語言的統計規律。

關鍵在這裡：模型**不是被直接灌入知識**，而是靠「預測能力」這個間接目標，**順便**把知識學起來。要能猜對「The capital of France is Paris」，它必須把「Paris」與「France」之間的關係存在參數裡。於是，知識是被「猜詞」這個任務**逼**出來的。

## 用一段可執行的概念示範

真實的推理需要模型權重和 tokenizer，但「猜下一個詞」的骨架可以用幾行概念程式碼表達。`logits` 就是模型對每個候選詞打的分數，`softmax` 把分數變成機率：

```python
# 概念示範：不是真的 PyTorch 模型，但骨架一模一樣
import math

# 模型內部的「下一詞分數」——每個候選詞一個分數（越高越可能是下一個）
logits = {"fast": 2.1, "quickly": 1.7, "forward": 0.9, "慢慢地": 0.8}

def softmax(scores):
  exp = {w: math.exp(s) for w, s in scores.items()}
  total = sum(exp.values())
  return {w: e / total for w, e in exp.items()}

probs = softmax(logits)
for word, p in sorted(probs.items(), key=lambda x: -x[1]):
  print(f"{word:>8}  {p*100:.0f}%")

# →     fast  42%
# →  quickly  31%
# →  forward  11%
# →  慢慢地  16%   ← 抽籤可能抽到任何一個！
```

> 真正的模型不會只輸出這 4 個詞——字典有 10 萬+ 個詞，它會替每個詞算一個機率。上面只是把數字縮小，讓你看得清楚。

## 為什麼「只會猜下一個詞」看起來卻無所不知

這是最大的謎團，答案也最漂亮：**語言本身是壓縮的知識**。

當你讓一個人類猜「愛因斯坦提出____理論」的下一個詞，他能猜對「相對論」，是因為他真的知道物理。模型沒有「真的知道」，但它讀過天文數字的文字，讓它在統計層面掌握了「相對論」幾乎總緊跟在「愛因斯坦提出」後面。**猜對一個詞，靠的是全世界的知識在語言裡的足跡。**

而且生成是**遞迴**的：模型每次只往前推一個詞，但把它自己剛生成的那個詞接回去，再猜下一個。一個字一個字，一整個段落就被「自己接著自己」地產生了。

## 這個心智模型，解釋了很多現象

一旦你接受「LLM = 猜下一個詞的機器」，很多困惑立刻有了解答：

| 現象 | 解釋 |
|---|---|
| 為什麼它講話這麼流暢 | 它受過天文數字的「講話」訓練，語言的統計規律早就內化 |
| 為什麼它會一本正經胡說八道（幻覺） | 有些「下一詞」猜起來很順，但事實是錯的——見 `llmcore-05-hallucination` |
| 為什麼它偶爾會改口 | 每次輸出都是抽籤，問第二次可能抽到不同籤 |
| 為什麼它不知道「今天的股價」 | 它只學過訓練截止前的文字，之後的世界它沒看過 |
| 為什麼它能寫程式 | 程式碼也是一種文字，而且極其規律，特別好「猜」 |

## 最重要的一句話

LLM 不懂、沒有意識、也不是在思考。它的本質，是**一台在十萬詞的字典上、反覆做「下一個詞抽籤」的機器——只是抽籤的技巧，是在整個網際網路上練出來的。**

理解了這一點，下一步就是拆解它的零件：語言不是以「字」為單位（`llmcore-02-tokens`），它能看到的範圍有限（`llmcore-03-context`），而這個「抽籤」可以調成更保守或更大膽（`llmcore-04-sampling`）。

#### Q: LLM 在生成文字時，每一次輸出的本質是什麼？

* 從網路上複製一段既有的句子

* 替字典裡每個詞算機率，再從這個分布抽一個詞

* 在記憶體裡搜尋最相似的句子

* 把使用者的問題逐字重排

> 💡 生成是遞迴的「下一詞抽籤」：模型對整個字典算機率，抽一個詞，接回去，再抽下一個。不是複製，也不是搜尋。
